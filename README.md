# Timeline - История компании OBRIO

Интерактивная временная шкала, которая визуально представляет ключевые этапы развития компании OBRIO.

## 📋 Описание

Веб-приложение демонстрирует важные события и достижения компании OBRIO в формате красивой интерактивной временной шкалы. Каждое событие содержит детальную информацию о ключевых вехах развития компании и её продуктов.

## ✨ Функциональность

- **Визуальная временная шкала** - центральная линия времени с событиями по обе стороны
- **Цветовое кодирование** - каждое событие имеет уникальный цвет для визуального различия
- **Адаптивный дизайн** - полная адаптация под мобильные устройства
- **Структурированный контент** - год, месяц, заголовок и подробное описание для каждого события

## 🎨 Дизайн

- Современный минималистичный интерфейс
- Мягкие тени и скругленные углы
- Светло-голубая цветовая схема (#f9f9ff)
- Типографика Segoe UI для оптимальной читаемости

## 📱 Адаптивность

Приложение полностью адаптировано для различных устройств:
- **Десктоп**: События расположены по обе стороны от центральной линии
- **Мобильные устройства**: Все события выравниваются по левому краю для удобства просмотра
